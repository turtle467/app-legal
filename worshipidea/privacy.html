プライバシーポリシー

最終更新日: 2026年8月9日

家族の崇拝プランナー（以下「本アプリ」）は、家族の崇拝で行う活動を選ぶ負担を減らすことを 目的としたiPhone / iPadアプリです。本アプリで記録した内容は、利用者の端末と、 利用者ご自身のiCloudの中だけで扱われます。 このページでは、何を扱い、何を扱わないかを具体的に説明します。

本アプリは非公式のアプリです。エホバの証人の公式アプリや公式サイトではなく、 教義の解説や聖書解釈を提供するものでもありません。

1. 提供者

turtle（以下「当方」）
お問い合わせ: turtle467developer@gmail.com

2. アカウント登録は必要ありません

本アプリの利用にあたり、氏名・メールアドレス・電話番号などの登録は不要です。 当方は利用者を識別する情報を一切保有しません。

3. 本アプリに保存される情報

本アプリで入力・記録した次の情報は、利用者の端末内、および 4. iCloudでの同期についてに記載のとおり利用者ご自身のiCloudに保存されます。

  • 家族構成: 大人・未就学・小学生・中高生がそれぞれ「いるか、いないか」の別。 年齢・氏名・人数など、個人を特定しうる情報は入力しません。
  • 普段の崇拝の時間: おおよその所要時間の選択
  • 崇拝の記録: 選んだ活動の名称、予定した週と日時、実施したかどうか、 「またやりたい / まあまあ / 合わなかった」の評価、利用者が任意で書いたメモ、 選択した所要時間・雰囲気・準備の度合い、続きを次回に行うかどうか
  • あとでやりたい: 保存した活動の識別子
  • 自作のアイデア: 利用者が作成した活動のタイトル・概要・手順・持ち物・ 所要時間・対象年齢などの設定
  • アプリの設定: 外観（ライト / ダーク / 端末連動）、通知の曜日と時刻、 使い方案内を見終えたかどうかなど

これらの情報を当方が受け取ることはありません。 本アプリには、これらを当方のサーバーへ送信する機能そのものが実装されていません。 利用者ご自身が「お問い合わせ」を送る場合に何が送られるかは、 8. お問い合わせの送信についてをご覧ください（崇拝の記録は含まれません）。

4. iCloudでの同期について

本アプリは、Apple社が提供するCloudKitのプライベートデータベースを利用して、 同じApple IDでサインインした端末間でデータを同期します。

  • プライベートデータベースは利用者ご自身のiCloud領域です。 当方はその内容を参照することも、取り出すこともできません。
  • iCloudにサインインしていない場合や、iCloud Driveをオフにしている場合でも、 本アプリは端末内のみでそのまま利用できます。 現在の保存先は、アプリ内の 設定 → データ・プライバシー で確認できます。
  • 同期を止めたい場合は、端末の「設定」→ ご自身の名前 →「iCloud」から 本アプリの同期をオフにしてください。

5. ウィジェット・通知・読み上げについて

  • ウィジェット: ホーム画面に今週の予定を表示するため、 予定している活動の名称と週の情報を、同じ端末内の共有領域（App Group）に保存します。 端末の外へ出ることはありません。
  • 通知: 本アプリが使うのは端末内で完結するローカル通知です。 当方から通知を送ることはなく、そのために利用者の情報を取得することもありません。 通知の許可はいつでも端末の設定から取り消せます。
  • 読み上げ: 手順の読み上げはiOSの音声合成機能によって 端末内で処理されます。読み上げた内容が外部へ送信されることはありません。

6. 共有カードについて

「家族に知らせる」で作成する共有カードの画像とテキストは、端末内で生成されます。 作成した内容をメッセージやメールなどで誰に送るかは、利用者がiOSの共有シートで都度選択します。 当方へ自動的に送信されることはありません。

7. データの書き出しと読み込み

アプリ内の 設定 → データ・プライバシー から、記録をファイルに書き出し、 別の端末で読み込むことができます。

  • 書き出したファイルの保存先は、利用者がiOSの画面で選択します。
  • ファイルには崇拝の記録やメモが含まれます。保管と受け渡しにはご注意ください。
  • 当方が書き出したファイルを受け取ることはありません。

8. お問い合わせの送信について

本アプリには、感想・不具合・アイデアの要望を開発者へ送る機能があります （設定 → アプリ →「ご意見・お問い合わせ」）。 この機能は、利用者が自ら送信の操作をしたときにのみ動作します。

送信には、当方が運営するサーバーではなくApple社が提供するCloudKitを利用します。 送信ボタンを押すと、次の内容がCloudKit上の当方のデータベースへ保存され、当方が確認します。

  • 選択した種類（感想・ご意見 / うまく動かない / アイデアの要望 / その他）
  • 利用者が入力した本文（最大1,000文字）
  • 本アプリのバージョン、iOSのバージョン、端末の機種名
  • 送信した日時

利用者のお名前・メールアドレス・iCloudアカウントの情報を当方が受け取ることはありません。 また、崇拝の記録・家族構成・メモ・自作のアイデアが送信されることもありません。 そのため、いただいた内容へ個別にご返信することはできません。返信をご希望の場合は、 turtle467developer@gmail.com へ直接メールをお送りください。

本文は自由に入力できるため、ご連絡に必要のない個人情報を本文に含めないようご注意ください。 いただいた内容は、本アプリの改善のためにのみ利用します。

なお、誤操作や連続送信を防ぐため、送信は1分に1回、1日3件までに制限しています。 この判定は端末内で行っており、そのために当方が情報を取得することはありません。

9. 利用状況の分析・広告について

本アプリは、利用状況の分析データを一切送信していません。 広告配信・行動追跡のための仕組みも組み込んでいません。 第三者の分析ライブラリや広告SDKは一つも組み込まれていません。 他社のトラッキング用ドメインへ接続することもありません。

本アプリが通信を行うのは、iCloudでの同期と、利用者がお問い合わせを送るとき、 および「応援」を購入するときだけです。

10. 購入情報について

「応援」（アプリ内課金）の購入手続きは、すべてApple社のApp Store（StoreKit）が行います。 クレジットカード番号などの決済情報が本アプリに渡ることはなく、当方が取得することもありません。

応援は開発を支えていただくためのものです。購入によって機能が増えたり、 表示が変わったりすることはありません。

11. 第三者への提供

当方は利用者の情報を保有していないため、第三者へ提供することはありません。

12. データの削除

  • 個々の記録は、アプリ内の履歴からいつでも編集・削除できます。
  • アプリを削除すると、端末内に保存されたデータは削除されます。 iCloudに保存された分もあわせて削除する場合は、端末の「設定」→ ご自身の名前 → 「iCloud」→「アカウントのストレージを管理」から本アプリのデータを削除してください。
  • いずれの場合も当方側に控えは残りません。復元が必要になる可能性があるときは、 事前の書き出しをおすすめします。

13. お子さまの利用について

本アプリは家族での利用を想定していますが、当方は利用者を識別する情報を収集していません。 家族構成として扱うのは各年代が「いるか、いないか」の別のみで、 お子さまの氏名・年齢・写真などを入力する項目はありません。

14. 本ポリシーの改定

法令の変更や機能の追加に伴い、本ポリシーを改定することがあります。 重要な変更を行う場合は、本ページの最終更新日を改めるとともに、アプリ内でお知らせします。
